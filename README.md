# Barroc Intens :)

## Over het project ☺

Barroc Intens is een softwareproject waarin wij een applicatie ontwikkelen voor het bedrijf Barroc Intens. Het bedrijf verhuurt professionele koffieautomaten aan horecagelegenheden.

Door de snelle groei van het bedrijf zijn er communicatieproblemen ontstaan tussen de verschillende afdelingen. Informatie wordt op verschillende plekken opgeslagen, waardoor gegevens verloren gaan, afspraken niet goed worden doorgegeven en processen verkeerd verlopen.

Het doel van dit project is om deze problemen op te lossen met één centrale applicatie.

## Doelstelling

Wij ontwikkelen een Minimum Viable Product (MVP) waarmee medewerkers van Barroc Intens hun werkzaamheden efficiënter kunnen uitvoeren.

De applicatie moet:
- Informatie centraal opslaan en beschikbaar maken.
- De communicatie tussen afdelingen verbeteren.
- Bedrijfsprocessen automatiseren.
- Fouten door dubbele of verouderde gegevens verminderen.
- Medewerkers toegang geven tot informatie die bij hun functie past.

## Functionaliteiten

### Sprint 1: Fundament

Tijdens de eerste sprint ontwikkelen we het fundament van de applicatie.

De geplande functionaliteiten zijn:

- Inloggen met gebruikersaccounts.
- Werken met verschillende gebruikersrollen.
- Een dashboard tonen dat afhankelijk is van de gebruikersrol.
- Binnengekomen storingsaanvragen bekijken.
- Storingsaanvragen aanmaken als salesmedewerker.
- Bestaande storingsaanvragen bewerken als salesmedewerker.

## Werkwijze

We werken volgens de Scrum-methodiek.

Het project bestaat uit twee sprints van ieder drie weken.

Tijdens het project gebruiken we GitHub Projects om onze werkzaamheden te organiseren. We werken met een Product Backlog en Sprint Backlogs.

Iedere sprint bestaat uit:
1. Sprint Planning.
2. Ontwikkeling van de geselecteerde User Stories.
3. Testen en controleren van functionaliteiten.
4. Sprint Review.
5. Sprint Retrospective.
